# HD2PhysBoneTool

面向 Blender 4.x 到 5.2 的《Helldivers 2》物理骨制作插件。

## 当前能力

- 便捷转换MMD/VRM/VRC物理（有损）
- 衣物姿态驱动：设置源骨与目标骨后，可以让目标骨根据源骨动画时以设置的规则来驱动目标骨。
- `N > HD2 物理骨 > 物体模式 > JSON 参数预设` 支持弹簧、节点、碰撞体和链连接预设。节点可区分数值/方向应用，也可应用到整条链或从当前节点到链尾；分享 JSON 会严格校验后按类型存放，可在导入窗口重命名。
- 用户预设位置为 Blender 用户配置目录下的 `hd2_physbone/presets`；支持 `PROFILE`、`NODE`、`COLLIDER`、`CHAIN_LINK` 子目录，面板可打开根文件夹管理。
- 骨链参数预设可把当前项目已有弹簧配置批量分配给所选骨链；增加多链渐变/方向对齐和 31 位碰撞掩码编辑，跨项目或无效选区会拒绝。
- 编辑投影随工作骨架整体移动，支持按类别专注、节点球形独立显示、碰撞体试摆应用/还原；修改后重新执行检查。
- 新建骨链默认补无权重尾骨（已有明确末端不重复补，可关闭）；首次开启角限默认按下一 Rest 骨段对齐。
- 检查物理骨项目：检查结构与衣物姿态规则；有骨链时同求解器测试静止和小幅运动各 120帧。
- 物体模式和姿态模式相互独立的 N 面板，以及类型专属对象属性面板；
- 从活动骨沿唯一子级自动创建物理骨链，或从明确选择路径创建高级骨链；

## 快速工作流

1. 在物体模式选择用于制作的 Armature，打开 `N > HD2 物理骨` 并初始化项目。
2. 有 MMD 物理时，在源模型与刚体仍对齐的状态下点“一键轻量转换 MMD 物理（有损）”，再由 Batch 对齐／转移。整体移动应操作包含骨架、网格、刚体和 Joint 的 MMD 根。
3. 选择一个具有父骨的模拟起始骨，从活动骨自动延伸到末端创建骨链。
4. 通过 Chain、Node、Collider、Chain Link 和 Link Collision 的预览对象或 Outliner 条目进入
   对应属性面板。
5. 需要跨链共同运动时选择两条 Chain Curve 创建 Chain Link；选中 Link 后可为等长链创建
   同序节点 Link Collision。
6. 执行“检查物理骨项目”：除结构检查外，会用同求解器对静止 Rest 和小幅运动各跑 120 帧，弹出不收敛/动画回退警告及异常帧数。不自动改碰撞或限位参数。超过单次 256 骨容量、组件缺失或达到 8 秒预算会明确显示动力学检查未完成，短测通过不保证所有动画正常。统一工作流由 AQSDK 分别保存身体或头盔；仅修改物理参数时可在“文件 > 导出”更新独立配套包，必须先开启 AQSDK 独立模式并保存目标部位。

## 插件更新
在 Blender 的插件偏好设置中检查和安装更新。更新后需要重启 Blender。
